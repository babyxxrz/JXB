# 标定与坐标说明（朱玉贺 · 控制模块交付物）

对应《技术设计文档》5.1 手眼标定与坐标转换、5.2 工作区与容器配置。

## 1. 坐标系定义

### 1.1 图像坐标系（张鹏源 detect 接口输出）

- 原点在图像**左上角**，u 轴向右，v 轴向下，单位 px。
- 与接口契约 `detect` 中 `center_u_px / center_v_px` 一致。

### 1.2 机械臂基坐标系（本模块所有 mm 坐标）

- 原点与轴向以 **URDF / 实机 SDK 定义为准**：基座 `base_link` 处，红色 X 轴、绿色 Y 轴、
  蓝色 Z 轴（RViz 中勾选 TF → `base_link` 可查看，与任务 2 指导书一致）。
- 单位 mm，z 轴向上。桌面平面高度记为 `z_grasp_mm`（配置项，实机测量确认）。
- **禁止直接将像素值当作毫米值**：像素 → mm 必须经过标定变换（单应矩阵 H）。

## 2. 标定文件

- 路径：`src/dofbot_control/calibration/calibration_*.yaml`，
  由 `dofbot_config.yaml` 的 `calibration.file` 指定。
- 内容：`calibration_id`（标定版本号，pick_place 请求须携带一致版本）、
  3x3 单应矩阵 `h`、标定点数、最大残差、生成时间。
- 每次重新标定生成新版本号，旧记录通过 `calibration_id` 可追溯。

## 3. 标定流程（9 点法，验收 ≤10mm）

1. **布置**：固定摄像头与机械臂，桌面放置标定纸（或 9 个已知位置标记点），
   保证 9 个点分布在有效工作区内且相互分散，光照稳定。
2. **取图像坐标**：拍摄一帧，记录每个标记点的 `(u, v)` px。
3. **取机械臂坐标**：遥控/手推机械臂使夹爪中心依次对准各标记点，
   记录基坐标系 `(x, y)` mm（z 取桌面平面高度，不需对准时下压）。
4. **整理 CSV**（`points.csv`，第一行可写表头）：

   ```csv
   u_px,v_px,x_mm,y_mm
   320,240,0.0,0.0
   ...
   ```

5. **生成标定**：

   ```bash
   ros2 run dofbot_control hand_eye_calibrate --points points.csv --out calibration.yaml --id cal-20261031-a
   ```

   输出单应矩阵、各点残差与最大残差。
6. **验收校验**：另取 9 个测试点（可与标定点不同位置）重复步骤 2-4，然后：

   ```bash
   ros2 run dofbot_control validate_calibration --calibration calibration.yaml --points test.csv
   ```

   最大误差 ≤ 10 mm 为 PASS（F1 验收：平面定位误差 ≤10mm）。
7. **生效**：把新标定文件放到 `src/dofbot_control/calibration/`，更新
   `dofbot_config.yaml` 的 `calibration.file`，重新编译/同步后在板卡上重启控制模块。

## 4. 工作区与容器配置

- `workspace`：有效工作区 = 相机可见 ∩ 标定有效 ∩ 机械臂可达 ∩ 路径无障碍 的交集，
  至少 120×120 mm。当前数值为占位值，**须实机确认**后写入
  `src/dofbot_control/config/dofbot_config.yaml`：
  - `x_min_mm/x_max_mm/y_min_mm/y_max_mm`：工作区边界；
  - `z_grasp_mm`：抓取高度（桌面平面）；
  - `z_lift_mm`：搬运抬升高度（须高于容器上沿，路径无障碍）。
- `bins`：红/黄/蓝/绿四个容器的中心坐标与释放高度 `z_release_mm`，实机确认。
- `robot.gripper_open_deg / gripper_close_deg`：夹爪开合角度，实机校准。
- 越界处理：控制服务与分拣闭环双重校验，越界拒绝运动并上报
  `OUT_OF_WORKSPACE`（对应技术设计文档 9.1）。

## 5. 标定版本管理

| 版本号示例 | 说明 |
|---|---|
| `sim-sample` | 仿真示例（0.4mm/px 近似映射），仅联调用，**禁止用于实机验收** |
| `cal-20261031-a` | 实机标定，版本号含日期与序号，随标定文件一起归档 |

`pick_place` 请求中的 `calibration_id` 必须与当前加载标定一致，否则拒绝执行
（错误码 `CALIBRATION_MISMATCH`），防止旧标定被误用。
