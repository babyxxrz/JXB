# 接口样例消息(联调参照)

联调时双方以本文件中的样例为唯一验证标准;字段名、类型、单位与《技术设计文档》第 7 章一致,不得偏离。
时间戳一律 Unix 毫秒(int64),未知坐标用 `null` 不用 `0`,无目标返回空数组。

## task_event(朱玉贺 → 严晨越,POST /api/events)

请求体为事件数组,单条或多条均可;相同 `event_id` 重复上报会被忽略(幂等)。

```json
[
  {
    "event_id": "T001-queued",
    "task_id": "T001",
    "occurred_at_ms": 1760000000000,
    "status": "queued",
    "color": "red",
    "x_mm": 12.5,
    "y_mm": -34.0,
    "z_mm": 40.0,
    "started_at_ms": null,
    "finished_at_ms": null,
    "error_code": null,
    "mode": "real",
    "result_basis": "none"
  },
  {
    "event_id": "T001-end",
    "task_id": "T001",
    "occurred_at_ms": 1760000002300,
    "status": "succeeded",
    "color": "red",
    "x_mm": 12.5,
    "y_mm": -34.0,
    "z_mm": 40.0,
    "started_at_ms": 1760000000800,
    "finished_at_ms": 1760000002300,
    "error_code": null,
    "mode": "real",
    "result_basis": "controller_only"
  }
]
```

- `status` 枚举:queued / running / succeeded / failed / skipped / stopped
- `color` 枚举:red / yellow / blue / green
- `mode` 枚举:real / fallback / simulation;HSV 兜底成功或跳过须标记 `fallback`,模拟引擎/演示数据一律标记 `simulation`(记录服务侧按枚举严格校验,非法值返回 422)
- `error_code` 只允许:LOW_CONFIDENCE / OUT_OF_WORKSPACE / CONTROL_TIMEOUT / STOP_REQUESTED(新增先改文档;该字段不做枚举校验,允许扩展)

## task_command(严晨越 → 朱玉贺,POST /api/command)

```json
{ "request_id": "r-20261030-001", "action": "start" }
{ "request_id": "r-20261030-002", "action": "stop" }
{ "request_id": "r-20261030-003", "action": "demo", "demo_action": "wave" }
```

返回(接收成功仅代表接受命令,不代表运动已完成):

```json
{ "accepted": true, "state": "running", "error_code": null }
```

> 说明:契约原枚举为 `action: enum(start, stop)`。`self_check`、`demo` 为看板功能所需的扩展
> (依据:技术设计 6.1「运行监控页:设备自检、演示动作触发与停止按钮」、5.4 演示动作组),
> 已与接口方约定:控制侧可实现,不能实现时须返回 `accepted=false` 并给出 error_code,不得静默忽略。
