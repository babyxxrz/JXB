# 接口样例消息(联调参照)

联调时双方以本文件中的样例为唯一验证标准;字段名、类型、单位与《技术设计文档》第 7 章一致,不得偏离。
时间戳一律 Unix 毫秒(int64),未知坐标用 `null` 不用 `0`,无目标返回空数组。

## task_event(朱玉贺 → 严晨越,POST /api/events)

请求体为事件数组,单条或多条均可;相同 `event_id` 重复上报会被忽略(幂等)。

```json
[
  {
    "event_id": "T001-queued",
    "task_id": "T001",
    "occurred_at_ms": 1760000000000,
    "status": "queued",
    "color": "red",
    "x_mm": 12.5,
    "y_mm": -34.0,
    "z_mm": 40.0,
    "started_at_ms": null,
    "finished_at_ms": null,
    "error_code": null,
    "mode": "real",
    "result_basis": "none"
  },
  {
    "event_id": "T001-end",
    "task_id": "T001",
    "occurred_at_ms": 1760000002300,
    "status": "succeeded",
    "color": "red",
    "x_mm": 12.5,
    "y_mm": -34.0,
    "z_mm": 40.0,
    "started_at_ms": 1760000000800,
    "finished_at_ms": 1760000002300,
    "error_code": null,
    "mode": "real",
    "result_basis": "controller_only"
  }
]
```

- `status` 枚举:queued / running / succeeded / failed / skipped / stopped
- `color` 枚举:red / yellow / blue / green
- `mode` 枚举:real / fallback / simulation;HSV 兜底成功或跳过须标记 `fallback`,模拟引擎/演示数据一律标记 `simulation`(记录服务侧按枚举严格校验,非法值返回 422)
- `error_code` 只允许:LOW_CONFIDENCE / OUT_OF_WORKSPACE / CONTROL_TIMEOUT / STOP_REQUESTED(新增先改文档;该字段不做枚举校验,允许扩展)

## task_command(严晨越 → 朱玉贺,POST /api/command)

```json
{ "request_id": "r-20261030-001", "action": "start" }
{ "request_id": "r-20261030-002", "action": "stop" }
{ "request_id": "r-20261030-003", "action": "demo", "demo_action": "wave" }
```

返回(接收成功仅代表接受命令,不代表运动已完成):

```json
{ "accepted": true, "state": "running", "error_code": null }
```

> 说明:契约原枚举为 `action: enum(start, stop)`。`self_check`、`demo` 为看板功能所需的扩展
> (依据:技术设计 6.1「运行监控页:设备自检、演示动作触发与停止按钮」、5.4 演示动作组),
> 已与接口方约定:控制侧可实现,不能实现时须返回 `accepted=false` 并给出 error_code,不得静默忽略。

## detect(张鹏源 → 朱玉贺,样例供联调参照)

```json
{
  "frame_id": "f-1760000000000-000042",
  "captured_at_ms": 1760000000000,
  "image_width_px": 640,
  "image_height_px": 480,
  "detections": [
    {
      "detection_id": "d-f-1760000000000-000042-0",
      "color": "red",
      "confidence": 0.934,
      "center_u_px": 320.5,
      "center_v_px": 240.1
    },
    {
      "detection_id": "d-f-1760000000000-000042-1",
      "color": "blue",
      "confidence": 0.61,
      "center_u_px": 128.0,
      "center_v_px": 96.0
    }
  ]
}
```

无目标时 `detections` 为**空数组**(不是 null):

```json
{
  "frame_id": "f-1760000000100-000043",
  "captured_at_ms": 1760000000100,
  "image_width_px": 640,
  "image_height_px": 480,
  "detections": []
}
```

- `frame_id` 格式:`f-<采集时间戳ms>-<6位序号>`,全局唯一、可排序、重启不重复
  (日期+序号方案重启后会重置,不满足 PRD"帧唯一标识"要求);
  `detection_id` = `d-<frame_id>-<帧内序号>`
- 坐标原点图像左上角,u 向右、v 向下;`center_u_px/center_v_px` 为
  bounding box 中心(像素);confidence ≥ 0.5 才输出(默认阈值)
- 帧新鲜度:同一帧超过 1s 未用于生成任务必须重采;任务完成后调用
  invalidate_cache(),禁止复用旧帧连续抓取
- HSV 兜底输出与本格式**完全一致**,由 task_event 的 mode=fallback 区分,
  控制层不用改解析逻辑

## model_release(杨泽 → 张鹏源,样例供联调参照)

```json
{
  "model_id": "yolov5s-v1.0",
  "model_file": "infer_project.tar.gz",
  "input_width_px": 640,
  "input_height_px": 640,
  "classes": ["red", "yellow", "blue", "green"],
  "trained_at_ms": 1760000000000,
  "val_map50": 0.83
}
```

> 说明:课程任务4 指定"模型适配工具→一键迁移"工具链,实际交付物为
> `infer_project.tar.gz`(产物 `yolov5s_bs1.om`),故 model_id/model_file
> 按 yolov5s 填写;`input_width_px/height_px` 以迁移配置为准;
> `classes` 顺序即类别索引顺序,顺序错误会导致颜色全乱。

## gesture(张鹏源 → 朱玉贺)—— 提案,待确认(TDD 待定项 T2)

```json
{
  "frame_id": "f-1760000000500-000099",
  "captured_at_ms": 1760000000500,
  "gesture": "like",
  "confidence": 0.91,
  "keypoints": [[320.1, 240.0], [330.0, 245.2]]
}
```

- 手势堆叠为附加演示功能,建议**独立 gesture 接口,不动 detect 契约**(TDD 7.2)
- `gesture` 枚举:fist / like / ok / palm / unknown;`keypoints` 为 21 个
  手部关键点 (u,v),检测不到手时 `gesture="unknown"`、`confidence=0`、`keypoints=[]`
- "手势→颜色"映射(T3)由控制侧配置,视觉只报类别
- 验收数字(T4)待小组补充,建议"四类手势准确率 ≥ 90%、单帧 ≤ 200ms"
