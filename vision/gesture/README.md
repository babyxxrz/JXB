# gesture — HRNet 手势识别(阶段6,TDD §4.6,附加演示功能)

积木堆叠的指令输入:HRNet 输出 21 个手部关键点,本模块判成
fist(握拳)/ like(点赞)/ ok / palm(张开手掌) 四类。

| 文件 | 说明 | 状态 |
|---|---|---|
| gesture_classifier.py | 关键点 → 四类手势,纯几何规则打分,与模型解耦 | ✅ 6 单测通过 |
| (待定) | HRNet 模型接入(engine 复用 detect_service 的 AclEngine) | ⏸️ 阻塞 T5 |

## 设计要点

- **与模型解耦(T5 未定也不影响)**:分类器只吃 21 个 (u,v) 关键点,
  MediaPipe 索引约定;HRNet 任意变体/来源的输出都能接
- **尺度归一**:距离除以"腕部→中指根"长度,与相机距离无关
- **规则打分**:四类各算 0~1 得分取最高,得分即伪置信度;< 0.6 判 unknown
- **阈值是起始值**:拿到真实 HRNet 输出后必须在板子上按实测关键点再调,
  当前测试只锁定"规则逻辑正确",不代表板上精度
